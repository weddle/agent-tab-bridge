# Agent Instructions

## Git publishing

- The main workspace agent may commit completed work to the current repository.
- Pushing is approval-gated, not categorically prohibited. Never push without Ryan's explicit approval in the current conversation. A direct request such as "push it" is that approval; execute the push rather than refusing, asking again, or only presenting the command.
- Push only the approved current repository, remote, and branch. Never force-push, delete a remote branch, or publish a new repository without separate explicit approval.
- Packet workers defined under `.omp/agents/` must continue to leave commits and pushes to the main workspace agent.
